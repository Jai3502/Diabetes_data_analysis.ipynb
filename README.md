# Project Description
This project focuses on analyzing a diabetes dataset using Python and machine learning techniques. It includes data preprocessing, exploratory data analysis (EDA), model training, and prediction to determine whether a patient is likely to have diabetes.
#  Diabetes Prediction Using Machine Learning

##  Project Overview
This project uses Python and machine learning to analyze a diabetes dataset and predict whether a person is diabetic based on medical features. It demonstrates data preprocessing, visualization, model building, and evaluation.

##  Dataset Information
The dataset contains the following features:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome  
  - `0` → Non-Diabetic  
  - `1` → Diabetic
